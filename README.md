# 기억을 먹는 탑

Java · Swing 기반 1인 덱 빌딩 로그라이크 RPG.

6명이 4주 동안 캐릭터 1종, 카드 20종, 일반 적 5종, 보스 1종, 10개 층을 구현합니다.

## 몀명 규칙

[Git 저장소 및 브랜치 규칙](outputs/GIT_WORKFLOW.md)을 먼저 읽어 주세요.

- `main`: 실행과 시연이 가능한 안정 버전
- `develop`: 다음 시연을 위한 통합 버전
- `feature/<작업명>`: 기능 개발
- `fix/<작업명>`: 오류 수정

## 게임 규칙
목표
= 10개 층을 올라 최상층 보스 처치

진행
= 전투 / 이벤트 / 상점 / 휴식 중 경로 선택

전투
= 매 턴 카드 5장 / 에너지 3 / 적의 다음 행동 공개

덱 성장
= 전투 승리 후 카드 3장 중 1장 선택 / 보상 건너뛰기 가능

기억
= 간직하면 카드 강화 / 잊으면 카드 제거 + 최대 체력 증가

휴식
= 체력 회복 / 카드 강화 중 하나 선택

자원 관리
= 체력·덱·골드는 다음 층에도 유지 / 전투용 일시 효과는 초기화

실패·재도전
= 사망 시 덱·골드·능력치 초기화 / 발견한 기억은 도감에 보존

핵심 재미
= 적의 행동에 대응하고, 남길 기억과 잊을 기억을 선택하며 성장

## 주차 계획


개발 환경, JDK 버전, 빌드 및 실행 방법은 프로젝트 구성 확정 후 추가합니다.
